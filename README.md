# FlipItNews - NLP News Classification

## 📌 Project Overview

FlipItNews is an NLP-based Machine Learning project that classifies
news articles into five categories:

- Business
- Entertainment
- Politics
- Sports
- Technology

The project demonstrates an end-to-end NLP pipeline from text
preprocessing and feature extraction to model training and evaluation.

## 🎯 Objective

To automatically classify news articles into their respective
categories using Natural Language Processing and Machine Learning.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## 🔄 NLP Pipeline

Text Cleaning
→ Tokenization
→ Stopword Removal
→ Lemmatization
→ TF-IDF
→ Model Training
→ Model Evaluation

## 🤖 Machine Learning Models

1. Naive Bayes
2. Decision Tree
3. K-Nearest Neighbors
4. Random Forest

## 📈 Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 💡 Key Insights

- Text preprocessing helps reduce unnecessary textual noise.
- TF-IDF provides an effective numerical representation of text.
- Multiple machine learning models were compared.
- The best-performing model was selected based on evaluation metrics.
